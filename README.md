# Griddle-slack-bot

# What this bot does
This bot is not a complex bot and does simple things, you can find a list of commands below so you can interact with this bot.

# List of commands
* /griddle-help - Lists all commands the bot can do
* /griddle-hello - Bot says hello
* /griddle-ping - Says the ping of the bot
* /griddle-catfact - Says a cat fact
* /griddle-stardance - Tell you when stardance ends
